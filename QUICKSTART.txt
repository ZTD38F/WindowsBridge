WindowsBridge 0.2 RC — GitHub-only

INSTALL / UPDATE
----------------
Paste into PowerShell:

irm https://raw.githubusercontent.com/ZTD38F/WindowsBridge/main/install.ps1 | iex

Everything WindowsBridge-related is fetched from GitHub. The installer:
- self-elevates with normal UAC;
- pins an immutable ZTD38F/WindowsBridge commit;
- downloads and verifies uv from astral-sh/uv GitHub Releases;
- builds an isolated local Python runtime;
- downloads and verifies OpenAI tunnel-client from GitHub Releases;
- validates the tunnel;
- installs SYSTEM autostart;
- rolls back to the previous source commit if validation fails.

FIRST INSTALL ONLY
------------------
The official OpenAI Secure MCP Tunnel requires:
1. Tunnel ID
2. Runtime API key with Tunnels Read + Use

A fresh computer must receive these once. They are then stored using Windows
DPAPI LocalMachine, so later reinstall/update is zero-input.

No personal VPS or WindowsBridge web server is used.

UNINSTALL
---------
irm https://raw.githubusercontent.com/ZTD38F/WindowsBridge/main/uninstall.ps1 | iex
