WindowsBridge 0.3.0 RC

INSTALL
-------
Paste into PowerShell:

irm https://raw.githubusercontent.com/ZTD38F/WindowsBridge/stable/install.ps1 | iex

FIRST INSTALL
-------------
1. UAC -> Yes.
2. OpenAI Tunnels opens.
   Name: WindowsBridge - <COMPUTERNAME>
   Copy tunnel_... and paste it into PowerShell.
3. Runtime API Keys opens.
   Name: WindowsBridge Runtime - <COMPUTERNAME>
   Restricted -> Tunnels: Read + Use
   Paste the key into the hidden prompt.
4. WindowsBridge installs and waits until the tunnel is READY.
5. ChatGPT Connectors opens.
   Name: WindowsBridge - <COMPUTERNAME>
   Connection: Tunnel
   Authentication: No authentication (NoAuth)

AUTO UPDATE
-----------
Enabled by default.
Channel: stable
Schedule: daily Windows Scheduled Task
Safety: immutable download -> staged install -> readiness check -> activate, with rollback on failure.
Status: durable generation/outcome ledger; current updater reports when a transport restart is required.
