WindowsBridge 0.3.0 RC

INSTALL
-------
Stable source (review before running):
https://raw.githubusercontent.com/ZTD38F/WindowsBridge/stable/install.ps1

1. Tunnel: create or reuse "WindowsBridge". Choose the correct
   Platform organization and ChatGPT workspace, then paste its tunnel_... ID.
2. Key: reuse a suitable Restricted key, or create "WindowsBridge"
   with Tunnels Read + Use.
   Paste only in the hidden PowerShell prompt.
3. ChatGPT Plugins: + -> Add custom MCP server -> WindowsBridge.
   Connection: Tunnel; select yours. Authentication: NoAuth.
   Review the warning, create and install the plugin.

VERIFY
------
Call a read-only WindowsBridge system-information tool in ChatGPT.
Local readiness alone does not prove ChatGPT connectivity.

NOTE
----
windowsbridge.pages.dev is configured to serve plain-text main/install.ps1,
not a website with a Copy command button. Elevated installation defaults to
stable. This PR does not change the installed stable version or live machine.

AUTO UPDATE
-----------
Enabled by default.
Channel: stable
Schedule: daily Windows Scheduled Task
Safety: staging -> readiness check -> activate, with rollback on failure.

CONTROL
-------
windowsbridgectl check
windowsbridgectl status
windowsbridgectl doctor
windowsbridgectl logs 200
windowsbridgectl restart
windowsbridgectl update
windowsbridgectl repair
windowsbridgectl ui
windowsbridgectl auto-update-enable
windowsbridgectl auto-update-disable

UNINSTALL (REMOVES LOCAL BRIDGE AND TASKS)
------------------------------------------
Review the official uninstaller file before running it locally.

DRAFT GRAPHICAL WIZARD (PR #40 ONLY)
-----------------------------------
On an interactive Windows PowerShell 5.1 desktop, the proposed installer
opens a WPF wizard for Tunnel ID and a masked Restricted API key, then shows
the ChatGPT plugin instructions after local tunnel readiness.
Use -ConsoleSetup to retain the original console prompts.
Noninteractive and auto-update runs do not open a GUI. Installing and
downloading still report progress in the PowerShell console.
No graphical changes are released to stable yet.
