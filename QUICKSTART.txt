WindowsBridge 0.2 RC — GitHub-only

INSTALL / UPDATE
----------------
Paste into PowerShell:

irm https://raw.githubusercontent.com/ZTD38F/WindowsBridge/main/install.ps1 | iex

Everything WindowsBridge-related is fetched from GitHub. The installer:
- self-elevates with normal UAC;
- pins an immutable ZTD38F/WindowsBridge commit;
- downloads and verifies uv from astral-sh/uv GitHub Releases;
- builds an isolated local Python runtime;
- downloads and verifies OpenAI tunnel-client from GitHub Releases;
- validates the tunnel;
- installs SYSTEM autostart;
- rolls back to the previous source commit if validation fails.

FIRST INSTALL ONLY
------------------
The installer guides the user through all required OpenAI steps.

STEP 1 — TUNNEL
It opens:
https://platform.openai.com/settings/organization/tunnels

Create:
Name: WindowsBridge

If a workspace selector appears, choose the ChatGPT workspace where you will
use WindowsBridge.

Copy the resulting tunnel_... ID and paste it into PowerShell.

STEP 2 — RUNTIME API KEY
It opens:
https://platform.openai.com/settings/organization/api-keys

Create:
Name: WindowsBridge Runtime
Access: Restricted
Tunnels: Read
Tunnels: Use

Paste the key into PowerShell. The input is hidden.

STEP 3 — CHATGPT CONNECTOR
After WindowsBridge passes tunnel validation, the installer opens:
https://chatgpt.com/#settings/Connectors

Use:
Name: WindowsBridge
Connection: Tunnel
Tunnel: WindowsBridge / the tunnel_... ID
Authentication: No authentication (NoAuth)

NoAuth is the MCP-server auth mode. The Secure MCP Tunnel itself is still
authenticated by the Runtime API key.

The key is stored using Windows DPAPI LocalMachine, so later reinstall/update
reuses it automatically.

No personal VPS or WindowsBridge web server is used.
